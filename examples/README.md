# Examples

This directory is split by audience:

- `handl/` — small curated handl language examples that do not map to a single crate.
- `http/` — a runnable HTTP + WebSocket server on the Handl epoll scheduler.
- `rust/` — Rust integration examples, run with `cargo run --example <name>`.

The full set of `lib-*` module examples is colocated with each crate, under `crates/lib-*/examples/<module>/`.
