# handl-lib-otlp

OpenTelemetry/OTLP module for the handl runtime.

Defines an abstract [`OtlpState`] and a [`Module`] adapter that
exposes `otlp.*` functions to handl programs. Concrete exporters live
in `handl-lib-otlp-std`.
